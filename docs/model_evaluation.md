# 模拟数据候选模型评估（2026-09-08）

## 一句话结论

代码已经证明：如果银行能提供风险发生前的 SLA、延期、人员、工单、可用率、投诉和舆情信号，模型可以利用这些字段提高突发风险识别。但新增字段全部是模拟值，结果只能用于验证技术方向，不能作为银行真实准确率。

## 特征和验证方式

- 32 项原有历史特征：风险分、事件历史、类别、整改、合同和系统信息；
- 8 项可选领先特征：字段可用标记，以及 7 项 SLA、延期、人员、工单、可用率、投诉和舆情指标；
- 三个按时间向后滚动的验证窗口；
- 使用历史窗口预测进行概率校准；
- 使用 F2 选择阈值，优先减少漏报；
- 第 35—44 周作为最后放行测试；
- `ACC/SUD` 编号只用于测试后分场景统计，从未作为模型输入。

## 三模型滚动验证

| 模型 | 三窗口平均 PR-AUC | 标准差 | 稳定性调整后得分 |
|---|---:|---:|---:|
| 逻辑回归 | 0.8858 | 0.0731 | 0.8676 |
| 随机森林 | 0.9276 | 0.0422 | 0.9170 |
| XGBoost | 0.9278 | 0.0437 | 0.9169 |

XGBoost 的平均值略高，但随机森林波动更小，最终选择随机森林，校准后的预警阈值为 0.30。

## 领先指标对照实验

为保证对照口径一致，以下两组均使用 XGBoost、相同时间窗口和相同标签，仅改变是否加入 8 项领先特征：

| 指标 | 不使用领先指标 | 使用模拟领先指标 |
|---|---:|---:|
| 测试 PR-AUC | 0.0858 | 0.7380 |
| 召回率 | 25.0% | 70.0% |
| 预警命中率 | 17.86% | 71.79% |
| 命中 / 漏掉 / 误报 | 10 / 30 / 46 | 28 / 12 / 11 |
| 突发型风险命中 | 0 / 30 | 18 / 30 |

当前正式模拟冠军随机森林的测试结果为：命中 28 条、漏掉 12 条、误报 12 条，召回率和预警命中率均为 70%。

## 必须保留的解释边界

领先指标是根据模拟场景生成的“假设性前置信号”。结果说明字段在算法管道中有用，但不证明银行真实数据也有同样效果。真实落地必须重新完成以下步骤：

1. 明确每个字段的业务定义、来源系统和采集时间；
2. 确认模型在当时确实能够看到该数据；
3. 使用真实历史时间段训练；
4. 保留从未参与调参的银行内部盲测时间段；
5. 由业务人员确认误报量是否可以承受。
